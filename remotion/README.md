# Remotion — Pixel Procurado

Instalação local e isolada para animações, cartelas, legendas e templates do canal.

```powershell
cd remotion
npm run studio
```

Comandos de validação:

```powershell
npm run compositions
npm run render:test
```

A composição inicial `PixelProcuradoBase` usa 1920×1080, 30 fps e cinco segundos.
